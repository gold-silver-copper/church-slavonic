# Synodal accent-paradigm fit

Every rule below was fitted **only** against `source`-partition printed forms and is
kept only when the engine's own accent implementation reproduces each of those
forms byte-for-byte. Held-out `evaluation` passages were never read while
fitting, so evaluation-partition tokens that these rules realise are genuine
generalisations rather than memorised strings.

Scope groups are refined from coarse to fine (number, case, gender, animacy) and
the coarsest granularity that fits the whole family is the one emitted, so real
accent mobility is stated rather than smoothed away.
