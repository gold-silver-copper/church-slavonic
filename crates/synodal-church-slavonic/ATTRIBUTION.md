# Attribution and bundled registry

The code in this package is offered under `MIT OR Apache-2.0` as declared in
`Cargo.toml`.

The small generated registry contains manually reviewed grammatical facts,
stable provenance identifiers, and citations derived from Hieromonk Alypy
(Gamanovich), *Grammar of the Church Slavonic Language*, corrected Ponomar web
edition through 2023-12-10, <https://www.ponomar.net/files/gama2/toc.html>.
The pinned 198-file research snapshot has aggregate SHA-256
`f140bcc4e1bd37d1179451da495c8b401ee4c9c42cecffcad0bd11423507c875`.

Alignment rows cite the English Wiktionary OCS lineage only as inherited
evidence; no Wiktionary definitions, page text, or bulk paradigm export is
bundled. The pinned Kaikki view has SHA-256
`fb20336e716d8f29d0c53bb4cc32f35065ad973ef8b496654c72bf542f876a83`
and remains governed by Wiktionary's CC BY-SA/GFDL lineage.

Ponomar Elizabeth-Bible passage IDs are evaluation provenance only. No Bible
passage text or other raw corpus is included in this crate.
