# Attribution and data boundary

The code in this package is offered under `MIT OR Apache-2.0` as declared in
`Cargo.toml`.

The rule identifiers and tests cite Hieromonk Alypy (Gamanovich), *Grammar of
the Church Slavonic Language*, corrected Ponomar web edition through
2023-12-10, <https://www.ponomar.net/files/gama2/toc.html>. The locally pinned
198-file research snapshot has aggregate SHA-256
`f140bcc4e1bd37d1179451da495c8b401ee4c9c42cecffcad0bd11423507c875`.
The package contains implemented grammatical facts and original Rust code, not
the source HTML or its prose.

Unicode handling follows Unicode Technical Note #41, revision 1. The locally
pinned PDF has SHA-256
`d4afd21e043d22655f1cb927fe4b130c83b15286ffbbfc6b9d70a43a48796579`.
Unicode data-file and technical-note terms remain those published by the Unicode
Consortium. No raw
corpus, Wiktionary export, dictionary scan, or noncommercial treebank is
packaged here.
