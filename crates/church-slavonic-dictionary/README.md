# church-slavonic-dictionary

Optional dictionary crate for the Church Slavonic rewrite pilot.

- Wiktionary (Kaikki) sense lookup and gloss access, re-keyed onto the
  `church-slavonic` facade's lemma keys (deterministic numeric homograph
  suffixes included) via each sense's pinned extracted lexeme.
- `lemmatize(form)`: form -> (lemma key, typed paradigm cell) readings,
  built by inverting the facade's paradigm enumeration (lazy in-process
  index; see the crate docs for the measured tradeoff).

Data is generated by `cargo xtask rewrite-dictionary` from
`data/dictionary/senses.json`; consistency against the facade is gated by
`cargo xtask check-structure`. Bundled sense data is CC BY-SA 4.0
(English Wiktionary via Kaikki); code is MIT OR Apache-2.0.
