# Attribution and bundled semantic registry

The code in this package is offered under `MIT OR Apache-2.0` as declared in
`Cargo.toml`.

The bundled registry is a small reviewed semantic index, not a reproduction of
a dictionary. Normative grammatical senses cite Hieromonk Alypy (Gamanovich),
*Grammar of the Church Slavonic Language*, corrected Ponomar web edition. Some
initial English gloss candidates were reviewed from Grigory D'yachenko's 1900
*Complete Church Slavonic Dictionary*, a public-domain scan pinned locally at
SHA-256
`24ba2f699d5ee407bef511275ab74e9b9e9a085dc7fbf400e92bb94aa9a53bc8`.

Ponomar Elizabeth-Bible examples are represented only by short token examples
and passage/source identifiers for provenance and evaluation. The package does
not contain a Bible corpus, Wiktionary dump, noncommercial treebank, or source
scan.
