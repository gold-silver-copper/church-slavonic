Church Slavonic Typography in Unicode

Previous Version n/a

Summary

This document provides an introduction and overview on how to encode text in the Church Slavonic language. It discusses proper font design and typography to represent a wide variety of Church Slavonic texts, both historical and modern. Implementation issues, as well as the topics of collation, input methods, romanization, and algorithmic generation of Cyrillic numerals are also addressed.
