Corpus Cyrillo-Methodianum Helsingiense

Vita Constantini

TEXT FILE

The text is based on the edition by Fran Tomšič (in Constantinus et Methodius Thessalonicenses: Fontes, recensuerunt et illustraverunt Franciscus Grives et Franciscus Tomsic = Radovi Staroslavenskog Instituta 4, Zagreb 1960). The file is not meant to be completely self-explanatory: it must be used with the edition.

A detailed transliteration table has no been composed, but the general principles are the same as in the transliteration of the Codex Suprasliensis.

The line numbers are to be interpreted as follows:

  • the first two digits: chapter

  • the next three digits: verse (in the edition)

  • the next digit: line number (in this file only)

  • the last digit: always zero, can be used for special purposes
