# Prompt: v1.1 — the consumer-defect program (fix the language, not the symptom)

Run in `~/Desktop/code/church-slavonic`. This repo's standing rules are the
program: after EVERY part, `cargo xtask accuracy` shows 100.00% / variant
gap 0 on every pinned table source, `cargo xtask check-registry` passes,
and all test suites are green; no code path ever hardcodes an output
string for a specific lemma — attested values enter ONLY through the
extractor from a pinned source; every wave gets a dated entry in the
NOTES.md diary; commit per part. The fact-resolution order lives in ONE
place (`church_slavonic_core::resolution`) and stays that way.

The occasion: the `vertograd` game (the crate's first real consumer,
`~/Desktop/code/vertograd`) audited hundreds of forms across four build
phases and rejected a specific list of crate outputs (its PHASE7/8/9
prompts' **[avoid]** entries). The 2026-08-31 diagnosis (below, all
**[verified]** against the committed tables) shows these are THREE
different defect classes needing three different fixes — resolution code,
rule defaults, and data — none of which is a monkey-patch, and one of
which is a defect in the AUDIT itself. Fix each in its proper layer.

## The diagnosis (verified 2026-08-31; trust it over re-derivation)

- **[verified]** `noun_phf.rs` holds `syn:ко́локолъ_2` (with attested
  «колокола̀») and NO base key `syn:ко́локолъ`. A runtime query for the
  bare lemma misses and falls to the rule, which answers an
  animate-shaped accusative for a bell. The lib.rs lookup invariants
  say `_n` keys resolve TO their base — nothing says a base query may
  be served BY a sole `_n` row.
- **[verified]** `verb_phf.rs` holds BOTH the milk-verb's forms
  («дои́ши, дои́тъ, дои́ла») and the reach-verb's («доидꙋ̀, до́йде,
  доидо́ша») — two homographs distinguished exactly by the accented
  citation form (дои́ти vs доитѝ). The consumer asked the aorist of
  «дои́ти» and received «дои́де», the reach-verb's.
- **[verified]** bare «стрищѝ» has no verb row (only `ocs:постригати`,
  `syn:и҆зостри́ти` neighbours); the rule guessed «стри́клъ». The -щи
  infinitive NEUTRALIZES the velar (стриг-ти vs пек-ти): the stem is a
  lexical property no rule can recover. Likewise «возжещѝ» → «вожжѝ».
- Rule-default defects reported by the consumer: animate-shaped
  accusatives for unattested inanimate masculines (кѷпарі́съ, прꙋ́дъ,
  ѡ҆́блакъ, перга́менъ, ѳѷмїа́мъ, ѻ҆гꙋре́цъ) and for the feminine
  i-stem «ꙗ҆́блонь» (acc «ꙗ҆́блонѧ»).
- **The audit's own defect**: vertograd's PHASE9 prompt rejected
  «пожа́тъ» as "participle-shaped" — but -ѧти verbs attest 3sg aorist
  in -ѧ́тъ («прїѧ́тъ») in the very corpus tradition. The arbiter is
  attestation, not the auditor's intuition. Part 4 settles it.

## Part 0 — The defect ledger (failing tests first)

`crates/church-slavonic/tests/consumer_defects.rs`: one test per
consumer-rejected form, exact expected output, each carrying a comment
naming its class (A resolution / B rule / C data) and, for class C, its
witness citation (source file + quoted line). All `#[ignore]`d at birth
with a reason string naming the part that will un-ignore it. Expected
values must each be JUSTIFIED in the test comment: a categorical rule of
the grammar (class B) or a quoted witness line (class C) — an
expectation nobody can cite does not enter the ledger; it goes to Part 4
for arbitration instead. Gate: suite green (ignored tests count as
green), accuracy untouched.

## Part 1 — Class A: the resolution layer (homographs)

Two lookup-semantics fixes in the runtime (and their mirror in the
extractor's finalize pass if it shares the code):

1. **A base query is served by its sole sense row.** If `syn:X` is
   absent but exactly one `syn:X_n` exists, the query for `X` resolves
   to that row before any rule. If SEVERAL `X_n` exist, keep today's
   behavior (the caller must choose a sense) — document that too.
2. **The accented citation form is the lexical key, everywhere.** The
   homograph pair дои́ти / доитѝ must resolve by the accent the caller
   supplied; find where the current lookup normalizes or falls back
   across accents and constrain it: an accent-exact hit always beats an
   accent-loose one, and an accent-contradicting row is never chosen
   while an accent-exact alternative (row OR rule) exists.

Update the lib.rs "Lookup semantics" invariant list — it is the contract
consumers read. Un-ignore the class-A ledger tests. Gate: accuracy
100/0 (these fixes change only off-key answers — prove it), NOTES entry
with before/after held-out recall (recall should not fall; report the
numbers either way).

## Part 2 — Class B: rule defaults where grammar is categorical

1. **Feminine i-stems never take the genitive-accusative.** Hard rule,
   no lexical exceptions in either recension: acc = nom for the whole
   class (ꙗ҆́блонь). Fix in the noun rule, not per-lemma.
2. **The unattested masculine defaults to inanimate.** Animacy marking
   is the marked case (persons and animals); a lemma the tables have
   never seen should answer acc = nom, letting the attested
   accusative-shape fact (the 0.9.0 mechanism) mark the animates it
   already marks. Measure the held-out corpus recall delta this causes
   and report it in NOTES — if recall DROPS, the default was wrong and
   this part reverts with the measurement recorded; the corpus, not the
   typology argument, has the last word.

Un-ignore the class-B tests. Gate: accuracy 100/0, recall reported.

## Part 3 — Class C: the witness source

A new pinned source, `data/witnesses.tsv`, one row per attested cell:
`recension, lemma, cell-id, form, source-file, quoted-line`. The
extractor ingests it exactly like any pinned source (same admission,
same finalize, same audit) — so witness rows are covered by the 100%
accuracy gate forever. Admission discipline: the quoted line must be
findable verbatim (normalization aside) in the named file under the
vertograd assets; a script `crates/xtask` gains a `check-witnesses`
verb that verifies every citation (offline-soft: skip with a warning
when the assets are absent).

Fill it from the disputed list by actually searching the fetched print:
- «стрищѝ» — find a stem-revealing form (стриже́тъ / стригꙋ́щ- /
  постри́же) in the Bible or service books; admit the present-stem /
  class-override fact (the 2-cell mechanism) from it.
- «возжещѝ» — the imperative is liturgically frequent («возжзѝ»);
  witness it and admit.
- «дои́ти» (milk) — witness an aorist if one exists in print; if none
  does, the cell stays rule-answered and the ledger test documents the
  accent-fix result (Part 1) instead — an unattested expectation is not
  invented.
- The inanimate accusatives of Part 2's list that DO occur in the print
  (ѡ҆́блакъ acc is common) — witness them as accusative-shape facts so
  they hold even if Part 2's default is ever revisited.

Un-ignore the class-C tests. Gate: accuracy 100/0 including the new
source; `check-witnesses` green.
